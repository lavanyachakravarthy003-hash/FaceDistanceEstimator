# Real-Time 2D Face Distance & Angle Estimator

## Overview
This project estimates the distance and horizontal angle of a person's face using a single 2D webcam and the pinhole camera model. It uses MediaPipe for real-time face detection and OpenCV for image processing.

## Features
- Real-time face detection
- Face width measurement in pixels
- Distance estimation using camera calibration
- Horizontal angle estimation
- Direction indicator (Left / Center / Right)
- Distance status (Too Close / Optimal / Too Far)
- FPS display
- Interactive dashboard

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy

## Installation

```bash
pip install opencv-python mediapipe numpy
```

## Run

```bash
python main.py
```

## Output

- Face Detection
- Distance Estimation
- Angle Estimation
- Direction
- FPS Counter
